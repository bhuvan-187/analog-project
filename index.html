ENGINEERING DOCUMENTATION

Model notes

Equation conventions, solver methods, and the implemented scope.

01

Long-channel MOSFET model

The device lab uses a square-law model, with the process parameter scaled by geometry: β = Kn(W/L). It reports current, transconductance, operating region, and channel-length modulation.

ID = β/2 · VOV² · (1 + λVDS)   (saturation)
Project documentation ↗
02

Common-source amplifier

The preserved lab calculates a DC Q-point, nonlinear time-domain response through coupling and bypass capacitors, small-signal gain, and loaded frequency response.

ID = (Kn/2)(VGS − VTH)²   (saturation)
03

Solver and accuracy boundary

Device node equations are solved algebraically. This is an educational compact model, not a SPICE engine. It omits body effect, subthreshold conduction, device capacitances, temperature, and noise.

Measured quantities in the virtual instruments are derived from model samples only.
04

Extended laboratory models

Common gate, source follower, cascode, source degeneration and two-stage amplifier calculations are linked to their controls and graphs. Current mirror, CMOS inverter, differential-pair OTA and finite-gain op-amp labs expose their assumptions beside live results.

All calculations are deterministic educational models; no SPICE engine is claimed.
